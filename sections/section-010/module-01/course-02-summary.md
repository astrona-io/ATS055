# Summary

Hubble exposes observed network flows with available endpoint, identity and verdict context. Local servers and Relay provide different scopes, while clients select and present records.

A forwarded event does not establish a correct application response, and missing records can reflect scope or collection limits. Correlate flows with routing, policy and application evidence to identify the first demonstrated failure rather than infer universal health from one observation.
