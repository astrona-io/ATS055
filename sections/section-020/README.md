# Enabling Layer 7 Protocol Visibility

This section covers enabling Layer 7 Protocol Visibility. It develops making Application Protocols Visible To Hubble through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Distinguish Layer 3 or 4 observations from Layer 7 context.
- Explain visibility-enabling policy and proxy participation.
- Account for encrypted payloads and protocol support.
- Evaluate observation changes without unintended enforcement.
