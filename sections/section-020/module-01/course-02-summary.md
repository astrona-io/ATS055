# Summary

Layer 7 visibility adds supported protocol context beyond addresses and ports. It depends on appropriate traffic processing and enabled observation rather than appearing automatically for every connection.

Encryption and protocol support can limit what is interpretable. Visibility policies can also affect enforcement, so review default-deny and application-rule semantics, collection cost and sensitive attributes before treating a change as harmless observation alone.
