# Know How to Use Hubble from the Command Line or the Hubble UI

This section covers know How to Use Hubble from the Command Line or the Hubble UI. It develops interpreting Hubble CLI And UI Views through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Choose local or Relay access for the intended scope.
- Interpret filters, time selection and request or reply direction.
- Use service maps as observed relationships rather than declared completeness.
- Distinguish client access failures from traffic failures.
