# Summary

Hubble clients retrieve and present observations from a selected server or Relay. Filters, time range and direction determine the visible population, while service maps summarize observed relationships.

An empty or inaccessible client view is not proof of absent traffic. Check permissions, connection scope and collection coverage, then correlate the relevant flow with application evidence before changing networking behavior.
